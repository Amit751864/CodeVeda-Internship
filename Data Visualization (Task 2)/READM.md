
# 📊 Task 2 - Exploratory Data Analysis (EDA)

## 📌 Project Overview

This task focuses on performing **Exploratory Data Analysis (EDA)** on the Customer Churn dataset. The objective is to understand the dataset, identify patterns, visualize data, and analyze relationships between numerical features using Python.

---

## 🛠️ Tools & Libraries

- Python 3
- Pandas
- Matplotlib

---

## 📂 Dataset

- Dataset Name: `churn-bigml-80.csv`
- Type: Customer Churn Dataset

---

## 📈 Visualizations Performed

### 1. Histogram

- Displays the distribution of **Account Length**.
- Helps understand the frequency distribution of data.

### 2. Box Plot

- Identifies outliers.
- Shows minimum, Q1, median, Q3, and maximum values.

### 3. Scatter Plot

- Shows the relationship between **Account Length** and **Total Day Minutes**.
- Helps identify trends and correlations.

### 4. Correlation Matrix

- Measures the relationship between numerical variables.
- Correlation values range from **-1 to +1**.

---

## 🔍 Analysis Performed

- Dataset inspection
- Statistical summary
- Data distribution analysis
- Outlier detection
- Relationship analysis
- Correlation analysis
